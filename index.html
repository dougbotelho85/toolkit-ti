Rede & Conectividade (Windows)

Liberar IP atual

ipconfig /release

Renovar IP (DHCP)

ipconfig /renew

Limpar Cache DNS

ipconfig /flushdns

Exibir Configurações de Rede Detalhadas

ipconfig /all

Redefinir Pilha TCP/IP

netsh int ip reset

Redefinir Winsock

netsh winsock reset

Ver Conexões Ativas e Portas (Netstat)

netstat -ano
Diagnóstico & Sistema (Windows)

Verificação de Integridade do Sistema (SFC)

sfc /scannow

Reparo de Imagem do Sistema (DISM)

DISM /Online /Cleanup-Image /RestoreHealth

Verificar e Corrigir Disco (CHKDSK)

chkdsk /f /r

Verificar S.M.A.R.T. do Disco (WMIC)

wmic diskdrive get status

Gerenciamento de Disco

diskmgmt.msc

Serviços do Windows

services.msc

Editor de Políticas de Grupo

gpedit.msc
Serviços & Monitoramento (Linux)

Status do Zabbix Agent

systemctl status zabbix-agent

Reiniciar Zabbix Agent

sudo systemctl restart zabbix-agent

Atualizar Lista de Pacotes e Sistema (APT)

sudo apt update && sudo apt upgrade -y

Verificar Espaço em Disco (Humano)

df -h

Verificar Uso de Memória RAM

free -h

Verificar Portas e Conexões Ativas

sudo ss -tuln

Monitor de Processos em Tempo Real

htop

Acompanhar Logs do Sistema em Tempo Real

sudo tail -f /var/log/syslog

Verificar Status do Firewall (UFW)

sudo ufw status verbose
